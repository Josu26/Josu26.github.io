# Personal portfolio

This repository powers Josué's professional portfolio at `https://josu26.github.io/`.

## Scope
A deliberately small, dependency-free, single-page site presenting verified public analytics work, general professional practice and clearly labelled personal R&D. Private employer repositories, internal metrics, client information and unreleased implementation details are excluded.

## Technology
- Semantic HTML and responsive CSS in `index.html`
- No JavaScript, tracking, web fonts, build tools or external runtime dependencies
- Keyboard-visible focus, skip link, reduced-motion support and mobile layout

## Updating content
1. Edit `index.html` text and project references.
2. Keep distinctions between public work, private R&D, professional experience and development areas.
3. Check every outbound link and run HTML/accessibility checks locally.
4. Verify the published page from a browser after GitHub Pages deploys.

## Provenance
This new page was authored independently of the old Helios template. Legacy template files may remain in Git history; no Helios assets or scripts are loaded by the new page.

## Privacy
Do not add proprietary code, organization-internal details, client metrics, screenshots, tokens, private repository links or company-owned designs.
